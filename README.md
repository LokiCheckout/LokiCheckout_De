**This Magento 2 module is an add-on package for adding some settings that feel good for the German market. Note that it is not required. It changes a couple of field labels and adds a grid `germany` variation of the default grid layout. Both can also be defined in a custom project-specific module.**

## Installation
Install this package via composer:
```bash
composer require loki-checkout/magento2-de
```

Next, enable this module:
```bash
bin/magento module:enable LokiCheckout_De
```
